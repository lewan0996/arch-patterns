# .NET architecture catalog

Choose system composition, deployable layout and module internals independently where compatible. Start with the [catalog](docs/catalog/README.md) or follow the [selection route](docs/catalog/selection.md).

The catalog provides architecture guidance and a [native template package](docs/catalog/microservices-solution.md) for a host-free microservices solution, a [flat service](docs/catalog/flat-service.md) with its operational baseline, and [anemic/direct-service PostgreSQL persistence](docs/catalog/direct-service-postgresql.md). Modular templates, creation skills and complete system examples remain planned. See [support and delivery](docs/catalog/delivery.md) for the exact evidence boundary.

The [glossary](CONTEXT.md) defines the vocabulary. The [decision map](https://github.com/lewan0996/arch-patterns/issues/1) indexes source decisions; [implementation issue #54](https://github.com/lewan0996/arch-patterns/issues/54) tracks delivery.
