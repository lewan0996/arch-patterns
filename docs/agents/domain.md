# Domain Docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs in `docs/adr/`.

Before exploring a relevant area, read `CONTEXT.md` and its applicable ADRs. If either is absent, proceed without requiring it; `/domain-modeling` creates these documents when needed.

Use terms from the `CONTEXT.md` glossary in issues, tests, and proposals. Surface any conflict with an existing ADR explicitly.
